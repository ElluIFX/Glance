## 关于 Glance

查看文件内容不应总要启动完整应用。Glance 提供快速、安静的文件预览体验，让浏览和筛选文件更直接。

在文件资源管理器中选中文件并按下空格，即可打开预览。再次按下空格，或在窗口失去焦点后，预览随即关闭。

相比同类软件，Glance 更注重稳定性与可靠性，在你需要预览文件时，Glance 保证随叫随到。

## 软件特色

- 快速预览文本、代码、Markdown、图片、音视频、PDF、压缩包和常见 Office 文档
- 高效可靠的长文本预览，灵活的图片缩放与拖动，任何现代功能都齐备了
- 钉住预览窗口，并同时打开多个独立预览，让文件成为您的便签
- 按内容类型记忆窗口尺寸与位置，适应您的使用习惯
- 可以从资源管理器，文件选择窗口和 Everything 中发起预览
- **可靠的多进程架构，即使遇到意外崩溃也能保持响应**
- **摈弃复杂的快捷键，只需要空格和您的鼠标，即可高效访问所有功能**
- **拒绝繁杂的插件系统，保持轻量、可靠、高效**

> 为保持轻量，部分格式的预览支持依赖于 Edge Webview2 运行时，如您的系统版本较低或手动精简了组件，可以从[这里](https://developer.microsoft.com/en-us/microsoft-edge/webview2)获取。

## 使用

从 [Releases](https://github.com/ElluIFX/glance/releases) 下载并安装 Glance。运行后，选中文件并按下空格即可预览；设置与退出入口位于系统托盘。
